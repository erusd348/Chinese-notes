📚 Grammar
Statement + 吗？ (Structure) Adding 吗 turns a statement into a yes/no question
你好吗？ nǐ hǎo ma? How are you?
S + Adv + Adj (Structure) Subject + adverb + adjective
我很好。 wǒ hěn hǎo. I'm very well.
S + 是 + N (Structure) Subject + 是 + noun
你是泰勒吗？ nǐ shì tài lè ma? Are you Tyler?
我是泰勒。 wǒ shì tài lè. I am Tyler.
