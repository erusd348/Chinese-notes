Merge the Sentences

Join each pair into one sentence using the connector

1.

Hints
因为 + reason (the marinating)，所以 + result (more tender). Keep 先 with the verb.
✍️ Combine: 因为…所以
2.
中zhōng国guó菜cài很hěn好hǎo吃chī。
做zuò菜cài太tài费fèi时shí间jiān了le。
Hints
虽然 + the good side (好吃)，但是 + the problem (费时间).
✍️ Combine: 虽然…但是
3.
他tā会huì腌yān肉ròu。
他tā会huì用yòng热rè锅guō冷lěng油yóu。
Hints
不但 + skill 1，而且 + skill 2 — two things he can do.
✍️ Combine: 不但…而且
4.
肉ròu炒chǎo得de太tài久jiǔ。

Hints

Hints
Praise first (味道很好 / 第一次做就很不错), then suggest gently (下次炒得快一点儿，肉会更嫩). Do not say 不好吃 directly.
评分维度 Rubric
• 得体性: praise before the suggestion — never a flat 不好吃
• 准确性: use this lesson's words 嫩 / 柴 / 炒得太久
• 复杂度: at least one sentence with 如果…就 or 因为…所以
